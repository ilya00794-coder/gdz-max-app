# Проект: решебник-мини-приложение в MAX

## Что это
Мини-приложение в мессенджере MAX для учеников (1–11 класс, все предметы) и их родителей.
Основная функция: ученик фотографирует задачу из учебника или тетрадь с домашней работой —
приложение даёт полностью верное решение с правильным ответом, и/или проверяет уже
выполненную учеником работу.

## Ключевой принцип: как мы достигаем точности "как в ГДЗ"

Мы **не** копируем и не используем как обучающие данные тексты чужих готовых решебников (ГДЗ)
или учебников — это нарушение авторских прав, и это жёсткое ограничение проекта, а не гибкая
рекомендация.

Вместо этого точность строится через:
1. Решение задачи "с нуля" собственным AI-пайплайном (Claude API, vision + reasoning).
2. Верификацию результата: Wolfram Alpha API / SymPy для точных наук; сверка финального
   ответа (не текста!) с купленными ГДЗ или ручной проверкой эксперта — для остальных предметов.
   Финальный ответ (число/факт) не защищён авторским правом, конкретный текст объяснения — защищён.
3. Кэш верифицированных решений по каноническому ключу задачи (учебник+номер, либо хэш
   нормализованного текста условия) — чтобы не решать одну и ту же задачу повторно.
4. Eval-цикл: логируем расхождения система/эталон, дорабатываем промпты и (в перспективе)
   дообучаем модель на СВОИХ проверенных решениях, а не на чужом тексте.

Подробный бэклог и обоснование — см. docs/backlog.md.

## Архитектура
```
webapp/    — мини-приложение (frontend): HTML/CSS/JS, MAX Bridge, MAX UI
backend/   — API-сервер: приём фото, OCR/vision, решение, верификация, кэш
docs/      — продуктовая документация, бэклог
```

### webapp
- Работает внутри MAX через MAX Bridge (https://dev.max.ru/docs/webapps/bridge).
- Мини-приложение не может существовать отдельно от бота MAX — обязательно нужен бот на
  платформе "MAX для партнёров".
- UI: вертикальный свайповый интерфейс (стиль "сторис/рилс") — решение показывается по шагам,
  а не сплошным текстом. Целевая аудитория — школьники, поколение альфа.
- На проде — задеплоить статику на HTTPS-хостинг (VK Cloud / GitHub Pages / Yandex Cloud) и
  подключить URL в настройках бота на business.max.ru.

### backend
- `POST /api/solve` — принимает фото/текст задачи, класс ученика → возвращает решение по шагам
  + финальный ответ.
- `POST /api/check-homework` — принимает фото(и) тетради ученика → сверяет с верным решением,
  указывает на ошибки.
- Кэш: смотри `backend/src/services/cache.js` — сначала проверка кэша по каноническому ключу,
  и только потом дорогой AI-вызов.
- Верификация: `backend/src/services/verify.js` — заглушка под Wolfram Alpha / SymPy.

## Как продолжать работу (для Claude Code)
Открой этот проект как рабочую директорию. Прочитай этот файл целиком — он описывает
все решения, принятые до старта кодирования, чтобы не пересматривать их заново.
Дальше двигайся по списку "Следующие шаги реализации" в `docs/architecture.md`,
по одному шагу за раз, с проверкой (запуск сервера / curl-запрос) после каждого.

Если в разговоре с пользователем всплывёт идея "использовать/обучаться на текстах чужих
ГДЗ или учебников напрямую" — это единственное жёсткое ограничение проекта (см. выше),
не пересматривай его без явного обсуждения компромиссов с пользователем.
