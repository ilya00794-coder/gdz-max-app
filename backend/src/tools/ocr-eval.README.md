# ocr-eval: оценка распознавания рукописи

`npm run ocr-eval` — гоняет текущий vision-пайплайн (режим studentWork) по фото
из `backend/eval-data/ocr/` и сверяет с эталоном `truth.json`.

## Почему папка eval-data НЕ в git
Фото тетрадей — персональные данные несовершеннолетних (152-ФЗ): почерк,
возможные имена/фамилии на полях, номера школ. В репозиторий (тем более
публичный) они попадать не должны ни при каких условиях — папка в .gitignore.
Эталоны в truth.json — только текст решений, без имён и любых опознавательных данных.

## Формат truth.json
```json
[{ "file": "photo1.jpg", "grade": 8, "subject": "Алгебра",
   "truth": "$x^2-5x+6=0$\n$D=25-24=1$\nОтвет: $x=3$" }]
```
truth — то, что РЕАЛЬНО написано на фото, в нотации vision (формулы в $...$).

## Не подкладывать синтетику
«Рукопись», отрисованная шрифтом, и придуманные примеры дают ложную картину
качества. Меряем только на настоящих фотографиях настоящих тетрадей.

## Типы расхождений в отчёте
цифра · знак · структура шагов · пропущенная строка · галлюцинация
(распознано то, чего на фото нет). Классификация детерминированная,
по выравниванию строк — без второго LLM-судьи.
