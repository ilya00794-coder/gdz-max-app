## Рабочие правила проекта (нарушение = переделка)
1. СТОП-И-ОТЧЁТ после каждого шага; явное добро Ильи перед следующим.
2. Не выходить за рамки задачи молча; любое отступление — сказать явно.
3. СНАЧАЛА ФАКТЫ, КОДА НЕ ПИШИ — когда Илья просит разбор/диагностику.
4. Канарейка после каждого изменения, ОБЕ стороны (починилось И не
   сломалось). Частичная канарейка маркируется честно (телефон — Ильи).
5. Проверять доставку так же, как её видит клиент: кэш — без ?cb=,
   API — preflight с Origin (см. project-handoff, «Правила проверок»).
6. Деплой фронта ТОЛЬКО scripts/deploy-pages.sh.
7. Канарейки к API — с заголовком X-Canary (иначе портят remote-выборку).
8. Ложный FALSE терпим, ложное verified — нет; при неоднозначности —
   unsupported. Запреты — прямые, требования — с условием применения.
9. Новый заголовок фронта = правка CORS allowedHeaders тем же коммитом.
