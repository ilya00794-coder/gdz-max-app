- **Фронт на Pages**: версия `294a69c-31.08.1121` (чертежи целиком). Сплит

## Что закрыто за последние заходы (31.08, вторая половина)
- **Линия №12 «чертежи» закрыта целиком, все 4 части** (10 из 11 замечаний
  судьи; 11-е — штриховка под графиком v–t в физике — отдельная задача
  в бэклоге). Принцип группы Б: модель называет параметры, система строит
  детерминированно; противоречие = отказ (services/figure.js).
  Части: прямоугольник/квадрат → углы (3 подтипа) → треугольник (элементы,
  честные совпадения по вычисленной геометрии) → четырёхугольники
  (параллелограмм ± диагонали, ромб, трапеция). Представительные формы
  заведомо неспециальные (62°, треугольник 46/72/62, равнобедр. 65/50/65,
  параллелограмм 1:1.6, ромб 1.5:1, трапеция не равнобокая).
  Все SVG одобрены Ильёй глазами. Переиспользуемые примитивы:
  angleArc/angleText (дуги углов), tickMark (равенство сторон).
- **Рефакторинг: единое поле figure** — слияние бывших visual+drawing
  (вынуждено грамматическим бюджетом). Legacy-адаптер: старые кэш-записи
  конвертируются на лету (legacyFigure), рендерятся, не прячутся.
- **Грамматический бюджет structured output ЗАМЕРЕН** (важно для ЛЮБОЙ
  правки схемы solver): запас — единицы строковых полей; каждый nullable-
  объект ≥10 полей. ПЕРЕД расширением схемы — пробить на живом API
  (скрипты проб в scratchpad сессии пишутся заново за минуту, паттерн:
  вытащить SolutionSchema, extend, messages.create c max_tokens 16;
  переполнение = 400 «grammar is too large» до генерации, бесплатно).
  Подробно: docs/backlog.md «Грамматический бюджет».
- **Сплит блока наглядности по классам**: subjectRules(subject, grade);
  математика 1–4 — только началка (22 строки вместо 60), математика 5–11
  и геометрия — оба блока. Канарейки всех срезов прошли.

## Рабочие правила проекта (нарушение = переделка)
1. СТОП-И-ОТЧЁТ после каждого шага; явное добро Ильи перед следующим.
2. Не выходить за рамки задачи молча; любое отступление — сказать явно.
3. СНАЧАЛА ФАКТЫ, КОДА НЕ ПИШИ — когда Илья просит разбор/диагностику.
4. Канарейка после каждого изменения, ОБЕ стороны (починилось И не
   сломалось). Частичная канарейка маркируется честно (телефон — Ильи).
5. Проверять доставку так же, как её видит клиент: кэш — без ?cb=,
   API — preflight с Origin (см. project-handoff, «Правила проверок»).
6. Деплой фронта ТОЛЬКО scripts/deploy-pages.sh.
7. Канарейки к API — с заголовком X-Canary (иначе портят remote-выборку).
8. Ложный FALSE терпим, ложное verified — нет; при неоднозначности —
   unsupported. Запреты — прямые, требования — с условием применения.
9. Новый заголовок фронта = правка CORS allowedHeaders тем же коммитом.
10. **Предупреждать Илью В МОМЕНТ запуска деплоя фронта и перезапусков**
    (он может проверять с телефона; правило про перезапуски распространено
    на деплой 31.08).
11. Правка схемы solver = сначала проба грамматического бюджета (см. выше).
