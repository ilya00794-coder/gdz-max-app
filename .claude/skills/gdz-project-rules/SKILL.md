# Правила точности и источников контента для решебника

## Жёсткое ограничение (не пересматривать без явного обсуждения с пользователем)
Никогда не предлагай и не реализуй:
- скачивание/парсинг текстов чужих готовых решебников (ГДЗ) или учебников для использования в базе ответов или как обучающих данных;
- обучение/дообучение модели на текстах чужих ГДЗ так, чтобы она воспроизводила похожий текст;
- хранение отсканированных страниц учебников целиком.

Это не техническое ограничение "пока не сделали", а сознательное решение проекта из-за
авторского права. Финальный числовой/фактический ответ не защищён авторским правом — его
можно использовать как эталон при сверке. Конкретный текст объяснения — защищён, копировать нельзя.

## Как достигать точности вместо этого
1. Решение генерируется "с нуля" через Claude API, с учётом класса ученика (методы, пройденные
   по программе на данный момент).
2. Верификация финального ответа: Wolfram Alpha / SymPy для точных наук; сверка с купленными
   ГДЗ или ручной проверкой эксперта — только финальный ответ, не текст объяснения.
3. Кэш верифицированных решений по каноническому ключу (учебник+номер, либо хэш условия) —
   см. cache.js.
4. При расхождении система/эталон — логировать, не пытаться "угадать" правильный ответ,
   не показывать пользователю неверифицированное решение как финальное без пометки.

## Проверка перед коммитом
Перед тем как считать задачу выполненной, убедись, что:
- новый код не содержит захардкоженных текстов из внешних источников решебников;
- любые "эталонные" данные, которые появляются в коде/тестах, помечены как собственные
  примеры проекта, а не скопированы с внешнего сайта.
